* ## 🎯 Escenario Elegido
**Escenario B: Análisis de Ventas de una Pequeña Empresa.**
El objetivo de este proyecto es analizar información comercial para generar indicadores básicos que permitan interpretar el desempeño de la empresa, utilizando Python (Pandas y Matplotlib) en el entorno de Google Colab.

## 📊 Descripción del Dataset
Se utilizó un dataset de ventas simuladas en formato CSV (ubicado en la carpeta `/datos`). El mismo contiene registros diarios con columnas de fechas, montos y ventas. La estructura respeta los lineamientos del Dataset 10.3 sugerido por la cátedra.

## 📂 Estructura del Repositorio
* `/datos`: Contiene el archivo `ventas.csv` con la información a procesar.
* `/scripts`: Contiene el script algorítmico principal `analisis_ventas.py`.
* `/resultados`: Almacena los gráficos de evolución generados por el script.

## 🚀 Instrucciones para ejecutar el script
1. Clonar este repositorio en tu entorno (local o Google Colab):
   `git clone https://github.com/BelLeal7/EquipoOE.git`
2. Posicionarse en la carpeta raíz del proyecto.
3. Ejecutar el script de análisis dentro de la carpeta correspondiente:
   `python scripts/analisis_ventas.py`
